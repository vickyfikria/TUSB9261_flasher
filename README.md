Burn firmware through TUSB926x Flash Burner

- Download TUSB926x Flash Burner from [TI download repository ](https://www.ti.com/tool/download/SLLC414)
- After TUSB926x Flash Burner launchee , attach the TUSB926x module. Flashburner will autodetect

  ![](/img/flashburner.png)
- Erase Flash first by clicking X button ![x button](/img/eraseflash.png)
- Select Binary file at File Path dropdown
- Ready to Write

  ![Ready to write](/img/readytowrite.png)
- Click Write button ![x button](/img/writeflash.png)
